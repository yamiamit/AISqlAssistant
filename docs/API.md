# API Reference

Base URL (local): `http://localhost:8000`. Interactive OpenAPI docs are auto-generated by FastAPI at `/docs`.

All routes except `/api/auth/register` and `/api/auth/login` require `Authorization: Bearer <token>`.

## Auth — `backend/app/api/routes/auth.py`

| Method | Path | Description |
|---|---|---|
| POST | `/api/auth/register` | Create an account, returns a JWT + user |
| POST | `/api/auth/login` | Exchange email/password for a JWT + user |
| GET | `/api/auth/me` | Return the authenticated user |

## Database connections — `connections.py`

| Method | Path | Description |
|---|---|---|
| GET | `/api/connections` | List the current user's connections |
| POST | `/api/connections/test` | Test credentials or a connection string without saving |
| POST | `/api/connections` | Save a connection (auto-discovers + caches schema) |
| PUT | `/api/connections/{id}` | Edit a connection (re-discovers schema) |
| DELETE | `/api/connections/{id}` | Remove a connection |
| GET | `/api/connections/{id}/schema` | Return cached schema (tables/columns/PKs/FKs) |
| POST | `/api/connections/{id}/refresh-schema` | Force a fresh schema discovery |

## Chat — `chat.py`

| Method | Path | Description |
|---|---|---|
| POST | `/api/chat/query` | Run the full NL → SQL → validate → execute pipeline |
| GET | `/api/chat/conversations` | List conversations (`?search=` filters by title/prompt) |
| GET | `/api/chat/conversations/{id}` | Full conversation with all messages |
| DELETE | `/api/chat/conversations/{id}` | Delete a conversation |

`POST /api/chat/query` body: `{ "prompt": string, "db_connection_id": number, "conversation_id"?: number }`. Always returns `201` with a `Message` — even failures (invalid SQL, AI timeout, DB offline) come back as a normal message with `error_message` set, so the UI has one rendering path.

## Saved queries — `saved_queries.py`

| Method | Path | Description |
|---|---|---|
| GET | `/api/saved-queries` | List saved queries |
| POST | `/api/saved-queries` | Save a query (name, prompt, SQL) |
| DELETE | `/api/saved-queries/{id}` | Delete a saved query |

## PDF ingestion — `pdf.py`

| Method | Path | Description |
|---|---|---|
| POST | `/api/pdf/upload` | multipart: `file`, `db_connection_id`, `target_table` → extracted preview (nothing inserted yet) |
| POST | `/api/pdf/confirm` | `{ db_connection_id, target_table, records }` → parameterized bulk insert |

## Export — `export.py`

| Method | Path | Description |
|---|---|---|
| GET | `/api/export/csv/{message_id}` | Download a message's result set as CSV |
| GET | `/api/export/pdf-report/{message_id}` | Download a formatted PDF report (prompt, SQL, explanation, table, chart) |

PNG chart export has no backend endpoint — it's done client-side from the rendered chart via `html-to-image`.

## Error shape

Every error response is `{"detail": "human-readable message"}` (see `main.py`'s exception handlers), so the frontend's axios interceptor can display `error.response.data.detail` directly without special-casing endpoints.
